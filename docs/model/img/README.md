# 模型图导出目录

本目录只放 **从 `model/AIGIS.qea` 导出**的 PNG，不要放截图和手绘替代品。
导出的图由报告正文按图号引用。

## 应放文件

| 文件名 | 内容 | 图注（可直接复制） |
|---|---|---|
| `DG-01-Package.png` | 模型仓库四阶段包结构 | 图 1-1 模型仓库结构图（来源：EA 17 手工绘制；源文件 model/AIGIS.qea） |
| `DG-02-WBS.png` | L1–L3 工作分解结构 | 图 1-2 工作分解结构（来源同上） |
| `DG-03-Deploy.png` | dev / test / prod 三环境 | 图 1-3 三环境部署图（来源同上） |
| `DG-04-Component.png` | 五个构件与依赖 | 图 1-4 系统组件图（来源同上） |

图号按报告实际章节序号调整，正文、图注、图内标题三处必须一致。

## 导出参数

`Publish → Save as Image`：

- 格式 PNG
- 宽度 1600 px（高度按比例，不勾选拉伸）
- 背景 白色
- 勾选 `Include Diagram Frame` 可保留图名，否则用 Word 图注代替，二选一，不要重复

## 检查

- 打开 PNG 缩放到 100%，中文是否可读、无方块
- 图内不能出现 `TODO`、`xxx`、英文占位符
- 与 `model/README.md` 第 3 节图清单文件名一致
