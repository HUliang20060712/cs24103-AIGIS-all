# AIGIS 操作手册（B-推荐系统）

## 1 启动

```bash
docker compose up -d
psql -h 127.0.0.1 -p 15432 -U aigis -d aigis -f sql/schema.sql
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

网关入口：dev 8081 / test 8082 / prod 80；推荐服务固定 8083。

## 2 初始账号

| 环境 | 账号 | 密码 |
|---|---|---|
| dev | aigis | aigis |
| test | aigis | aigis_test |

## 3 推荐功能三步操作

1. 登录后进入“推荐”页；
2. 首次使用选择 2–3 个感兴趣类别（水体/植被/建筑/道路/农田/裸地）；
3. 列表展示 Top-10，点击卡片“不感兴趣”回传反馈。

## 4 常见问题

| 现象 | 处理 |
|---|---|
| 500 且日志有 Redis 连接错误 | 确认 6379 端口；服务会自动降级查库 |
| 返回空列表 | 检查 `item_meta` 数据与 `hot_rank` 当天记录 |
| 端口占用 | `lsof -i:8083`，改 `application-dev.yml` 的 `server.port` |
