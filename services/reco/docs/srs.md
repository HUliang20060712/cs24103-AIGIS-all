# AIGIS 需求规格说明书（初稿）

版本 v0.3　基线 M2（2026-11-27）　责任人：胡德伟（2024210548）

## 1 范围

系统面向遥感影像与地理空间数据，共 12 项功能：对话界面与多轮上下文、SSE 流式与 Markdown 渲染、RAG 知识库问答、推荐 API、用户偏好管理、协同与内容混合推荐、图片上传与识别记录、批量识别任务、分割任务与训练数据管理、分割结果可视化、跨服务调用、负载均衡与熔断降级。

不在本期：3D 地球、原生移动 App、在线支付、多租户 SaaS、实时协同标注。

## 2 角色

| 角色 | 主要诉求 |
|---|---|
| 遥感数据处理人员 | 批量分割、地物统计、结果导出 |
| GIS 分析人员 | 点位检索、相似地物、推荐流 |
| 文旅与自然资源业务人员 | 用自然语言拿到结论 |

## 3 B 模块功能需求

| 编号 | 需求 | 验收方式 |
|---|---|---|
| FR-B01 | 按用户偏好返回 Top-N，支持分页 | feed 返回 10 条且字段齐全 |
| FR-B02 | 记录点击/收藏/不喜欢反馈 | feedback 表新增一行 |
| FR-B03 | 偏好查询、覆盖、清空 | 三接口返回 200/204 |
| FR-B04 | 冷启动返回热门榜 | 新用户 feed 非空 |
| FR-B05 | Redis 不可用时降级查库 | 停 Redis 后接口仍 200 |
| FR-B06 | 相似物品按类别返回 | similar 返回同类物品 |

## 4 非功能需求

- 推荐接口 P95 < 200 ms（1,000 条交互规模）。
- 单测通过率 100%，行覆盖率 ≥ 60%。
- AI 使用记录随 PR 提交，缺失由 CI 阻断。
